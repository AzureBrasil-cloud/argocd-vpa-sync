argocd-vpa-updater {{ .Chart.AppVersion }} is installed in namespace {{ .Release.Namespace }}.

Open the dashboard:
{{- if .Values.ingress.enabled }}
{{- range .Values.ingress.hosts }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}
{{- end }}
{{- else }}
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "argocd-vpa-updater.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}
  http://localhost:{{ .Values.service.port }}
{{- end }}
{{ if not .Values.auth.enabled }}
WARNING: auth.enabled=false -- the dashboard and the endpoints that queue Git
commits are open to anyone who can reach the Service.
{{- else if .Values.auth.existingSecret }}
Log in as "{{ .Values.auth.admin.username }}" with the password whose hash is in
Secret {{ .Values.auth.existingSecret }} (key admin.password).
{{- else if .Values.auth.admin.passwordHash }}
Log in as "{{ .Values.auth.admin.username }}" with the password matching auth.admin.passwordHash.
{{- else }}
Log in as "{{ .Values.auth.admin.username }}" with the generated initial password:

  kubectl -n {{ .Release.Namespace }} get secret {{ include "argocd-vpa-updater.initialAdminSecretName" . }} \
    -o jsonpath='{.data.password}' | base64 -d; echo

Set auth.admin.passwordHash (or auth.existingSecret) to choose your own; the
initial-admin Secret is then removed.
{{- end }}
